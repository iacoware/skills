# Recipe app — Shared ownership fixture

- **Sources:** Recipe-app goals and concepts.
- **Current state:** Greenfield.

## Ordering criteria

- Alternate capture and search slices to maximize breadth.

## Themes

| Theme | Desired outcome | First validation |
|---|---|---|
| URL capture | A member imports recipes from structured pages. | 1 |
| Pasted fallback | A member imports unreadable pages by pasting text. | 3 |

## Cross-functional concerns

- **Authorization:** Cookbook membership scopes writes.
- **Validation and errors:** Decode structured extraction output.
- **Operability:** Log adapter timeouts and cost.
- **Accessibility and security:** Progress is announced accessibly.
- **Data integrity and recovery:** Edit regenerates embeddings.

## NOW

### 1. URL extraction core *(Theme: URL capture)*

---

**Includes**

- Open part of the shared extraction adapter for JSON-LD URL pages.

**Verification**

- Import one structured page through the adapter.

**Outcome**

- Members import structured recipe pages.

### 2. Semantic lookup *(Theme: URL capture)*

---

**Includes**

- Query embeddings generated by URL imports.

**Verification**

- A query returns an imported recipe.

**Outcome**

- Members find imported recipes.

### 3. Reopen extraction for pasted text *(Theme: Pasted fallback)*

---

**Includes**

- Reopen the shared extraction adapter and add pasted-text normalization and LLM decoding.

**Verification**

- Paste a paywalled page and save its recipe.

**Outcome**

- Members recover when URL fetch is unreadable.
